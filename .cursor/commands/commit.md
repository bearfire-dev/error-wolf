Commit the work you did as a sensible set of commits (ideally not capturing
changes to files you didn't touch).

Commit preferences:

- Use commit subjects in this style: `(feat): ...`, `(fix): ...`, `(chore): ...`, `(refactor): ...`.
- Keep commit subjects brief and specific.

Example:

```bash
git add -A
git commit -m "(chore): short description"
```
